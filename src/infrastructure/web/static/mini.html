สั่งเทรดเอง (override บอท)

สั่งเองข้ามด่านกรอง (operator override) · paper = ไม้จำลอง · live (ปลดล็อกแล้ว) = ออเดอร์จริง

“เทรดลม (PAPER)” = เอเจนต์เทรดจำลองบนราคาจริงของ Bitkub — ตัวเลขทั้งหมดด้านบนเป็นผลจริงของการเทรดลม หักค่าธรรมเนียมสองขาแล้ว · “บัญชีจริง” แสดงยอด wallet จริงเมื่อเชื่อม key (อ่านอย่างเดียว) · การเทรดด้วยเงินจริงถูกล็อกไว้ (paper-only) ต้องปลดล็อก LIVE เองด้านล่าง (ปุ่มแดง)
