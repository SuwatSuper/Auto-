# Auto- — SET Daily Edge Finder

ระบบหา "จุดเข้ารายวัน" เชิงสถิติสำหรับหุ้นไทย (SET) — ไฟล์เดียวจบ: `daily_edge_finder.py`

## เริ่มใช้งาน

```bash
pip install yfinance pandas numpy            # ต้องมี 3 ตัวนี้
python daily_edge_finder.py                  # รันจริง (ดึงราคาสด แล้วฟันธงออร์เดอร์พรุ่งนี้)
python daily_edge_finder.py --demo           # รันสาธิตแบบไม่ต้องต่อเน็ต (ข้อมูลสังเคราะห์)
python daily_edge_finder.py --offline        # ใช้ราคาจากแคชที่เคยดึงไว้
python daily_edge_finder.py --fast           # ค้นแบบย่อ (เร็วขึ้น ผลหยาบกว่า)
python daily_edge_finder.py --selftest       # รันเทสต์ทั้งชุด (ต้องมี pytest)
```

ตัวเลือกเพิ่มเติม: `--universe {QUALITY19,SET50,SET100}` `--capital 30000`
`--max-positions 3` `--limit-tickers N`

## เวอร์ชัน HTML — `set_daily_trader.html` (ไม่ต้องติดตั้งอะไรเลย)

ดับเบิลคลิกเปิดไฟล์ในเบราว์เซอร์ → ระบบตรวจตัวเอง 74 รายการ → ค้นสมการครบ 565,248 แบบ
→ ยืนยัน out-of-sample 2 ช่วง → จำลองพอร์ต → ฟันธงออร์เดอร์วันถัดไป → **จบการทำงาน**
(ใช้เวลา ~7 วินาทีบนข้อมูล 37,500 แถว, ~12 วินาทีบน 62,500 แถว)

- ทำงานทั้งหมดในเครื่องคุณ ไม่มี library ภายนอก ไม่ส่งข้อมูลออก
  (ยกเว้นตอนกดปุ่ม "ลองดึงราคาสด" เท่านั้น)
- เปิดครั้งแรกจะรันด้วย **ข้อมูลสาธิต (สังเคราะห์)** เพื่อพิสูจน์ว่าโปรแกรมทำงานครบ
- ใส่ราคาจริงได้ 2 ทาง: ลากไฟล์ CSV มาวาง (ไฟล์ `price_cache_daily.csv` จากเวอร์ชัน Python
  ใช้ได้ทันที) หรือกดปุ่มดึงราคาสด (ผ่านตัวกลางที่เปิด CORS — อาจไม่สำเร็จแล้วแต่เครือข่าย)
- สมุดบันทึกออร์เดอร์เก็บใน localStorage ของเบราว์เซอร์ → เปิดวันถัดไประบบตัดสินผลไม้เก่าให้เอง

เครื่องยนต์คำนวณถูกพอร์ตมาจาก `daily_edge_finder.py` และตรวจสอบแล้วว่าให้ผล
**ตรงกันทุกตัวเลข** บนชุดข้อมูลเดียวกัน (ทดสอบ 5 สมการครอบคลุมทั้งโหมด %/ATR,
market/limit และตัวกรอง ADX/วอลุ่ม/สภาพตลาด)

## ระบบทำอะไร

1. **ดึงราคา** 5 ปี (yfinance, auto-adjust) + แคชไว้ใช้ซ้ำ/ออฟไลน์
2. **คำนวณอินดิเคเตอร์ครั้งเดียวบนข้อมูลเต็ม** แล้วค่อยแบ่ง in-sample / out-of-sample
   ด้วย mask + embargo (ไม่มี warm-up ซ้ำ ไม่มี look-ahead)
3. **ค้นสมการแบบครบทุกความเป็นไปได้** 565,248 สมการ (~95 วินาที บนหุ้น 50 ตัว 5 ปี)
   จาก 10 ตระกูลสัญญาณ × โหมดออก (%/ATR) × ตัวกรอง (ADX/วอลุ่ม/สภาพตลาด)
   × วิธีเข้า (market/limit) × ระยะถือ 1-5 วัน
4. **ยืนยันบนข้อมูลที่ไม่เคยเห็น 2 ช่วง** ต้องผ่านทั้งคู่ แล้วให้เกรด
   - **A** = ถึงเป้า (WR ≥ 80% และกำไร ≥ 2%/วัน)
   - **B** = มี edge จริงแต่ไม่ถึงเป้า
   - **-** = ตก
5. **จำลองพอร์ตจริง** (เงินจำกัด, board lot 100 หุ้น, ค่าคอมทั้งขาซื้อ-ขาย,
   ถือพร้อมกันได้จำกัด) → ได้ "กำไร %/วัน จริง", max drawdown, equity curve
6. **ฟันธงออร์เดอร์ของวันทำการถัดไป** (ราคาซื้อ/TP/SL/จำนวน lot) + บันทึกลงสมุด
   แล้ววันถัดไปตัดสินผลให้อัตโนมัติจากราคาจริง → track record ที่ตรวจสอบได้
7. **dashboard_daily.html** สรุปทุกอย่างในหน้าเดียว

## สิ่งที่ระบบจะไม่ทำ

ไม่ตกแต่งตัวเลขให้ดูดี: ถ้าไม่มีสมการถึงเป้า WR 80% + 2%/วัน ระบบจะบอกตรง ๆ ว่าไม่ถึง
แล้วแสดง "ดีที่สุดที่ยืนยันได้จริง" พร้อมตัวเลขทั้งหมด — โดยที่ทุกตัวเลข
หักต้นทุน 0.514% แล้ว, ไม้ที่ชนทั้ง TP และ SL ในแท่งเดียวนับเป็น "แพ้",
gap เปิดทะลุ SL คิดที่ราคาเปิดจริง, และ "ชนะ" หมายถึงกำไรสุทธิ > 0 (ไม่ใช่แค่แตะ TP)

ไม่ใช่คำแนะนำการลงทุน · ผลในอดีตไม่การันตีอนาคต · ผู้ใช้รับความเสี่ยงเอง
