# Tor Life OS — Personal Operating System

ระบบจัดการชีวิต + การเงินส่วนตัวแบบไฟล์เดียว (single-file HTML) ทำงานได้ในเบราว์เซอร์
ไม่ต้องติดตั้ง ไม่ต้องต่อเซิร์ฟเวอร์ ข้อมูลเซฟถาวรในเครื่อง (localStorage) อัตโนมัติ

**ไฟล์ระบบล่าสุด:** [`TorLifeOS_v5_3.html`](./TorLifeOS_v5_3.html)

## วิธีใช้
1. ดาวน์โหลด `TorLifeOS_v5_3.html`
2. เปิดด้วย Chrome / Safari / Edge
3. ใช้งานได้เลย — ข้อมูลเซฟในเครื่องอัตโนมัติ ควรกด **สำรอง JSON** เดือนละครั้ง

## Changelog — v5.3 (UI polish + สติกเกอร์/อีโมจิ + แก้บั๊ก)

### 🎨 เพิ่มสติกเกอร์/อีโมจิ (ลุคขาว สะอาดตา หรู ยังคงเดิม)
- **แท็บทั้ง 10** มีไอคอนกำกับด้านบนชื่อ
- **การ์ดสถิติหัวจอ** (💎 ความมั่งคั่ง · 🛟 รันเวย์ · ⏰ งานค้าง · ❤️ คะแนน)
- **ไอคอนหมวดอัตโนมัติ** จับคำจากชื่อรายการ/หมวด (🏠 ผ่อนบ้าน, 🐱 อาหารแมว,
  🏥 ค่ารักษาแมว, ⛽ น้ำมัน, 💊 ยา, 🛡️ ประกัน, 🌱 สวนข่า ฯลฯ) ใช้ทั่วทั้งระบบ —
  ทั้งชิปเลือกหมวด, รายการ, งบ, to-do, ประกัน, เป้าหมาย
- **เหรียญความสำเร็จ** เปลี่ยนเป็นสติกเกอร์อีโมจิ (ล็อก = ขาว-ดำจาง / ปลดล็อก = สีเต็ม)
- **หน้าจอว่าง (empty state)** มีสติกเกอร์ + ปุ่มลิงก์ข้ามไปแท็บที่เกี่ยวข้อง
- **Toast** แสดงไอคอนตามบริบท (✅ สำเร็จ / ⚠️ เตือน / ℹ️ ข้อมูล)

### 🔗 เชื่อมต่อระหว่างหน้าต่าง
- หน้าจอว่างบนแดชบอร์ด/งบการเงิน มีลิงก์ "→ ไปที่แท็บ..." กดกระโดดได้ทันที
- ตรวจสอบเส้นทางข้อมูลครบ: ตั้งค่า→หมวด→ฟอร์ม→แดชบอร์ด→งบ,
  พอร์ต→สัดส่วน/เงินสำรอง/เป้าหมาย/งบดุล/ความมั่งคั่งสุทธิ

### 🐛 แก้บั๊ก / ปรับ UX
- **[กลาง]** แดชบอร์ด: กดขยายหมวดในตาราง "รายจ่ายเทียบงบ" ไม่รีเฟรช/รันแอนิเมชัน
  ทั้งหน้าอีกต่อไป (แยกฟังก์ชัน `renderBudget` — ลื่นขึ้น)
- **[ต่ำ]** สีพื้นหลังหน้าเพจโหมดขาวปรับให้เข้ากับธีม (#F7F7F8) แทนสีครีมเดิม
- **[ต่ำ]** ไฮไลต์ชิปหมวดเร็วซิงก์กับ dropdown เมื่อเปลี่ยนหมวดด้วยมือ
- **[ต่ำ]** ข้อความ toast สื่อความหมายชัดขึ้นด้วยไอคอนตามบริบท

### ✅ ผ่านการทดสอบ
เปิดในเบราว์เซอร์จริง (Chromium) กดครบทุกแท็บ + เพิ่มรายการ/เป้าหมาย/งาน +
สลับธีม + ขยายหมวด → **ไม่มี error ระดับ crash/runtime เลย**
