# Tor Life OS — Personal Operating System

ระบบจัดการชีวิต + การเงินส่วนตัวแบบไฟล์เดียว (single-file HTML) ทำงานได้ในเบราว์เซอร์
ไม่ต้องติดตั้ง ไม่ต้องต่อเซิร์ฟเวอร์ ข้อมูลเซฟถาวรในเครื่อง (localStorage) อัตโนมัติ

**ไฟล์ระบบล่าสุด:** [`TorLifeOS_v5_7.html`](./TorLifeOS_v5_7.html)

## วิธีใช้
1. ดาวน์โหลด `TorLifeOS_v5_7.html`
2. เปิดด้วย Chrome / Safari / Edge
3. ใช้งานได้เลย — ข้อมูลเซฟในเครื่องอัตโนมัติ ควรกด **สำรอง JSON** เดือนละครั้ง

## Changelog — v5.7 (ระดับผู้บริหาร — งบละเอียด + แผนผังวงกลม + สั่งงานผ่านที่ปรึกษา)

ยกระดับจาก "แอปหัดออมเงิน" เป็น **ระบบบริหารการเงินระดับผู้บริหาร** — เห็นที่มาที่ไปของเงินทุกก้อน

- 🏛️ **แดชบอร์ดฐานะการเงิน**: สินทรัพย์ · หนี้สิน · **ส่วนของเจ้าของ (Equity)** เห็นชัดว่ามีอะไรเท่าไหร่
- 🥧 **แผนผังวงกลม (donut) ทั่วระบบ** — สัดส่วนสินทรัพย์ · โครงสร้างหนี้ · พอร์ตลงทุน (แยกรายตัว) ·
  **สัดส่วนรายรับตามธุรกิจ** · โครงสร้างรายจ่ายรายหมวด · ใช้พาเลตต์สีที่ผ่านการตรวจ accessibility (colorblind-safe)
- 💼 **การ์ดรายธุรกิจละเอียด**: รายรับ/รายจ่าย/กำไรเดือนนี้ + สุทธิสะสม + **อัตรากำไร (margin)** พร้อมแถบ
- 🧾 **งบกำไรขาดทุน (P&L)** ในหน้างบการเงิน — แยกรายได้ตามธุรกิจ · Operating Profit · Net Cash · อัตรากำไร
- ⚡ **สั่งงานผ่านที่ปรึกษาได้จริง** (ทั้งโหมดออฟไลน์และ AI): เช่น
  `เตือน ต่อใบขับขี่ 2/8` · `เพิ่มงาน ปิดงบ สิ้นเดือน ทุกเดือน` · `จ่ายค่ากิน 250` · `รายรับ ฟรีแลนซ์ 28000` ·
  `ออม 5000` · `ตั้งเป้า เที่ยวญี่ปุ่น 50000` · `เพิ่มธุรกิจ ร้านกาแฟ` · `เพิ่มหนี้ บัตรเครดิต 20000`
  — ระบบทำให้จริง เข้าใจวันที่ไทย (พรุ่งนี้/สิ้นเดือน/2 ส.ค./อีก 3 วัน) และ**ใส่อิโมจิที่เหมาะกับงานให้อัตโนมัติ**
- 🔗 **ทุกอย่างลิงก์กัน**: สั่งเพิ่มรายการ → อัปเดตทันทีทั้งแดชบอร์ด, งบ, พอร์ต, ธุรกิจ, เป้าหมาย, ความมั่งคั่งสุทธิ

> ยังยึดหลักเดิม: **ไม่โกหก ไม่แต่งตัวเลข** — ทุกตัวเลขมาจากรายการจริงที่บันทึก ธีมขาวสะอาดระดับผู้บริหาร

## Changelog — v5.6 (คุยกับที่ปรึกษาในแชท)

เพิ่ม **กล่องแชท** ในแท็บ 🧠 ที่ปรึกษา — พิมพ์ถามได้เลย มี 2 โหมด:

- **โหมดออฟไลน์ (ค่าเริ่มต้น · ไม่ต้องตั้งค่าอะไร):** เอนจินกำหนดค่าเดิมตอบจาก
  ข้อมูลจริงในเครื่อง แยก [ข้อเท็จจริง]/[วิเคราะห์]/[ข้อเสนอแนะ] มี basis อ้างอิงจริง
  บอก "ข้อมูลไม่เพียงพอ" ตรง ๆ — **สร้างข้อมูลปลอมไม่ได้** · มีปุ่มคำถามตัวอย่าง
- **โหมด AI (ทางเลือก · ใส่ Claude API Key เองที่แท็บตั้งค่า):** คุยได้ทุกเรื่องแบบลึก
  ต่อ Claude (ค่าเริ่มต้น `claude-opus-4-8`; เลือก Sonnet 5 / Haiku 4.5 ได้) โดยส่ง
  system prompt กฎเหล็ก 8 ข้อ + สรุปข้อมูลจริงของผู้ใช้ไปด้วย เพื่อบังคับให้ยึด
  ข้อมูลจริงและไม่แต่งเรื่อง

**ความเป็นส่วนตัว/ความปลอดภัย:**
- โหมด AI จะส่ง "สรุปข้อมูลการเงิน/สุขภาพ/งาน" ไป Anthropic เพื่อวิเคราะห์ (แจ้งชัดในแอป)
  และมีค่าใช้จ่ายตาม API Key ของผู้ใช้เอง
- **API Key เก็บในเครื่องนี้เท่านั้น และไม่ถูกใส่ลงไฟล์สำรอง JSON** (กันคีย์รั่ว)
- ไม่ใส่ Key ก็ใช้โหมดออฟไลน์ได้เต็มที่

> เพิ่มเฉพาะฟิลด์ `settings.aiKey` / `settings.aiModel` — โครงสร้างข้อมูลเดิมกู้คืนได้ปกติ

## Changelog — v5.5 (คณะที่ปรึกษา Multi-Agent — วิเคราะห์จริง ไม่โกหก)

เพิ่มแท็บ **🧠 ที่ปรึกษา** = ระบบวิเคราะห์แบบ Multi-Agent ที่ยึดหลัก
**"ความถูกต้องมาก่อนความมั่นใจ"** — ออกแบบให้ *โกหกไม่ได้เชิงโครงสร้าง*

**ทำไมเป็น engine กำหนดค่าได้ (deterministic) ไม่ใช่ LLM สด:**
แอปนี้เป็นไฟล์เดียวทำงานออฟไลน์ ไม่มีเซิร์ฟเวอร์ — ถ้าต่อ LLM สดจะ (ก) ต้องมี
API key + ออนไลน์ ทำลายความเป็นส่วนตัว และ (ข) เป็นตัวที่ "แต่งเรื่อง" ได้ง่ายที่สุด
ตรงข้ามกับ "ไม่โกหก" · engine กำหนดค่าอ่านเฉพาะข้อมูลจริงในเครื่อง ทุกตัวเลข
ตรวจสอบย้อนได้ 100% และ *สร้างข้อมูลปลอมไม่ได้*

**เอเจนต์ (13 ตัว) — สอดคล้องกับข้อมูลจริงในระบบ:**
CEO · Data Verification · Risk Management · Strategy · Finance · Accounting ·
Business · Investment · Tax · Legal · Health · Productivity · Learning

**ยึดกฎ 8 ข้อครบ:**
1. ไม่เดา/ไม่สร้างข้อมูลเอง — ทุกตัวเลขมาจาก `db` จริง
2. ข้อมูลไม่พอ → บอก **"ข้อมูลไม่เพียงพอ"** + ระบุว่าต้องการอะไรเพิ่ม
3. แยก **ข้อเท็จจริง / วิเคราะห์ / ข้อเสนอแนะ** ชัดเจนทุกการ์ด
4. ระบุ **ระดับความเชื่อมั่น** (สูง/กลาง/ต่ำ) ผูกกับความครบของข้อมูล
5. **ทะเบียนความเสี่ยง** เรียงตามความรุนแรง (ร้าย/กลาง/ต่ำ) + ผลกระทบ
6. เปรียบเทียบทางเลือก (เช่น เติมเงินสำรอง vs โปะหนี้) พร้อมเหตุผล
7. เรื่องเงิน/สุขภาพ/กฎหมาย มี **disclaimer** และแจ้งข้อจำกัดเมื่อข้อมูลไม่ครบ
8. ทุกข้อสรุปมี **basis (อ้างอิงตัวเลขจริง)**

**พิสูจน์แล้วว่าอ่านข้อมูลจริง:** พอกรอกรายรับ/รายจ่ายจริง ความน่าเชื่อถือข้อมูล
ขยับ 36% → 61% และการ์ด Finance โชว์ตัวเลขตรงกับที่กรอกเป๊ะ · ส่งออกรายงานเป็น
.txt / คัดลอกได้

> เพิ่มเฉพาะเลเยอร์วิเคราะห์ ไม่แตะโครงสร้างข้อมูลเดิม — กู้คืน JSON เก่าได้ปกติ
