# Tor Life OS — Personal Operating System

ระบบจัดการชีวิต + การเงินส่วนตัวแบบไฟล์เดียว (single-file HTML) ทำงานได้ในเบราว์เซอร์
ไม่ต้องติดตั้ง ไม่ต้องต่อเซิร์ฟเวอร์ ข้อมูลเซฟถาวรในเครื่อง (localStorage) อัตโนมัติ

**ไฟล์ระบบล่าสุด:** [`TorLifeOS_v6_0.html`](./TorLifeOS_v6_0.html)

## วิธีใช้ (บนคอมพิวเตอร์ / เว็บ)
1. ดาวน์โหลด `TorLifeOS_v6_0.html`
2. เปิดด้วย Chrome / Safari / Edge
3. ใช้งานได้เลย — ข้อมูลเซฟในเครื่องอัตโนมัติ ควรกด **สำรอง JSON** เดือนละครั้ง

## ติดตั้งเป็นแอปบนแอนดรอยด์ 📱

มี 2 ทาง เลือกทางไหนก็ได้:

### ทาง A — PWA (ติดตั้งผ่าน Chrome, ง่ายสุด ไม่ต้องมีเครื่องมือ)
ไฟล์อยู่ในโฟลเดอร์ [`docs/`](./docs) พร้อมสำหรับ **GitHub Pages**
1. ไปที่ repo → **Settings → Pages** → ตั้ง Source เป็นบรานช์ที่มีโฟลเดอร์ `docs/` แล้วเลือกโฟลเดอร์ `/docs` → Save
2. รอสักครู่ จะได้ลิงก์ประมาณ `https://<username>.github.io/<repo>/`
3. เปิดลิงก์ด้วย **Chrome บนแอนดรอยด์** → กดเมนู (⋮) → **"ติดตั้งแอป / เพิ่มลงในหน้าจอหลัก"**
4. ได้ไอคอนบนหน้าจอ เปิดแบบเต็มจอ (ไม่มีแถบเบราว์เซอร์) และ **ใช้งานออฟไลน์ได้เต็มรูปแบบ** (service worker แคชไว้)

> อัปเดตแอป = แค่ push ไฟล์ใน `docs/` ใหม่ ผู้ใช้เปิดครั้งถัดไปก็ได้เวอร์ชันล่าสุด

### ทาง B — ไฟล์ APK จริง (โปรเจกต์ Android Studio)
โปรเจกต์ WebView ที่ฝังแอปไว้ครบอยู่ในโฟลเดอร์ [`android/`](./android) — build เป็น `.apk` ได้
1. ลง [Android Studio](https://developer.android.com/studio)
2. **Open** โฟลเดอร์ `android/` (มี Gradle wrapper ให้แล้ว Android Studio จะโหลด SDK/ปลั๊กอินที่เหลือเอง)
3. เมนู **Build → Build App Bundle(s) / APK(s) → Build APK(s)** → ได้ไฟล์ที่ `app/build/outputs/apk/`
4. ติดตั้ง APK ลงมือถือ (เปิด "ติดตั้งจากแหล่งที่ไม่รู้จัก") หรือส่งขึ้น Google Play ได้
   หรือ build ผ่านบรรทัดคำสั่ง: `cd android && ./gradlew assembleDebug`

> แอปทำงานออฟไลน์ 100% ตั้งแต่ติดตั้ง (ฝัง HTML ไว้ใน assets) · ขอสิทธิ์ INTERNET เฉพาะไว้ใช้โหมด AI/โหลดฟอนต์เท่านั้น
> รายละเอียดเพิ่มเติมดูที่ [`android/README.md`](./android/README.md)

> **ย้ายข้อมูลข้ามอุปกรณ์:** เครื่องเดิมกด **สำรอง JSON** แล้วเครื่องใหม่กด **กู้คืนจาก JSON** — ข้อมูล PWA/แอป/ไฟล์ HTML เก็บแยกกันตามที่เปิด

|------|---------|

| รายการ | ประวัติทั้งหมด + เทียบราคาต่อหน่วยย้อนหลัง + แก้ไข/ค้นหา |
| ธุรกิจ | ผลประกอบการแยกรายธุรกิจ + อัตรากำไร |
| พอร์ต | สินทรัพย์ · หนี้สิน · สัดส่วน (donut) · กำไร/ขาดทุนยังไม่รับรู้ |
| สุขภาพ | น้ำหนัก/นอน/ออกกำลัง + ยา/วัคซีน/ผลตรวจ |
| ตาราง/เอกสาร | To-do (ทำซ้ำรายเดือนได้) · ประกัน/สิทธิ · เอกสารสำคัญ |
| เป้าหมาย | ติดตามเป้า + พยากรณ์ + เหรียญความสำเร็จ |
| งบการเงิน | งบกำไรขาดทุน (P&L) · งบรายรับ-รายจ่าย · กระแสเงินสด · งบดุล · แนวโน้มความมั่งคั่ง |
| ที่ปรึกษา | แชทกับที่ปรึกษา (ออฟไลน์/AI) — ถามตัวเลข/สั่งงานได้ + คณะที่ปรึกษา Multi-Agent |
| ตั้งค่า | ธีม · หมวด · เป้าระบบ · สำรอง/กู้คืนข้อมูล |

## Changelog — v5.5 (คณะที่ปรึกษา Multi-Agent — วิเคราะห์จริง ไม่โกหก)

เพิ่มแท็บ **🧠 ที่ปรึกษา** = ระบบวิเคราะห์แบบ Multi-Agent ที่ยึดหลัก
**"ความถูกต้องมาก่อนความมั่นใจ"** — ออกแบบให้ *โกหกไม่ได้เชิงโครงสร้าง*

**ทำไมเป็น engine กำหนดค่าได้ (deterministic) ไม่ใช่ LLM สด:**
แอปนี้เป็นไฟล์เดียวทำงานออฟไลน์ ไม่มีเซิร์ฟเวอร์ — ถ้าต่อ LLM สดจะ (ก) ต้องมี
API key + ออนไลน์ ทำลายความเป็นส่วนตัว และ (ข) เป็นตัวที่ "แต่งเรื่อง" ได้ง่ายที่สุด
ตรงข้ามกับ "ไม่โกหก" · engine กำหนดค่าอ่านเฉพาะข้อมูลจริงในเครื่อง ทุกตัวเลข
ตรวจสอบย้อนได้ 100% และ *สร้างข้อมูลปลอมไม่ได้*

**เอเจนต์ (13 ตัว) — สอดคล้องกับข้อมูลจริงในระบบ:**
CEO · Data Verification · Risk Management · Strategy · Finance · Accounting ·
Business · Investment · Tax · Legal · Health · Productivity · Learning

**ยึดกฎ 8 ข้อครบ:**
1. ไม่เดา/ไม่สร้างข้อมูลเอง — ทุกตัวเลขมาจาก `db` จริง
2. ข้อมูลไม่พอ → บอก **"ข้อมูลไม่เพียงพอ"** + ระบุว่าต้องการอะไรเพิ่ม
3. แยก **ข้อเท็จจริง / วิเคราะห์ / ข้อเสนอแนะ** ชัดเจนทุกการ์ด
4. ระบุ **ระดับความเชื่อมั่น** (สูง/กลาง/ต่ำ) ผูกกับความครบของข้อมูล
5. **ทะเบียนความเสี่ยง** เรียงตามความรุนแรง (ร้าย/กลาง/ต่ำ) + ผลกระทบ
6. เปรียบเทียบทางเลือก (เช่น เติมเงินสำรอง vs โปะหนี้) พร้อมเหตุผล
7. เรื่องเงิน/สุขภาพ/กฎหมาย มี **disclaimer** และแจ้งข้อจำกัดเมื่อข้อมูลไม่ครบ
8. ทุกข้อสรุปมี **basis (อ้างอิงตัวเลขจริง)**

**พิสูจน์แล้วว่าอ่านข้อมูลจริง:** พอกรอกรายรับ/รายจ่ายจริง ความน่าเชื่อถือข้อมูล
ขยับ 36% → 61% และการ์ด Finance โชว์ตัวเลขตรงกับที่กรอกเป๊ะ · ส่งออกรายงานเป็น
.txt / คัดลอกได้

> เพิ่มเฉพาะเลเยอร์วิเคราะห์ ไม่แตะโครงสร้างข้อมูลเดิม — กู้คืน JSON เก่าได้ปกติ

- 🔍 **ค้นหาในแท็บรายการ** — พิมพ์ชื่อรายการ/หมวด/โน้ต/ธุรกิจ ค้นข้ามทุกเดือนได้ทันที
- ⌨️ **กด Enter เพื่อบันทึก** — ในหน้ากรอกและหน้าต่างแก้ไข ลงบัญชีเร็วขึ้น
- 📈 **แนวโน้มความมั่งคั่งสุทธิ** — ระบบเก็บ snapshot อัตโนมัติทุกเดือน วาดเป็นกราฟเส้น
  ในแท็บงบการเงิน เห็นหนี้ลด/เงินสำรองโตขึ้นตามเวลา (สร้างกำลังใจในการปลดหนี้)
- ⏳ **นับถอยหลังสัญญาฟรีแลนซ์** — การ์ดบนแดชบอร์ดบอก "เหลืออีกกี่เดือน" ถึงวันสัญญาหมด
  พร้อมเตือนให้เตรียมช่องทางรายได้สำรองล่วงหน้า (เปลี่ยนสีตามความเร่งด่วน)

> โครงสร้างข้อมูลเดิมใช้ต่อได้ 100% — เพิ่มเฉพาะฟิลด์ `snapshots` (กู้คืน JSON เก่าได้ปกติ)
