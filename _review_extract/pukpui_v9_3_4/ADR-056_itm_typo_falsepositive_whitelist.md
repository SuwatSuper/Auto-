# ADR-056 — whitelist FP typo: "บริสุทธิ์" + "กระเบื้องพื้น" · rebaseline 0563245c→be6398d2

**วันที่:** 2026-06-20 · **สถานะ:** ACTIVE · **golden:** `0563245c…` → `be6398d2…`
**สั่งโดย:** ผู้ใช้ (ตรวจ ITM010/011/019 รายคำ → ยืนยัน FP 2 คำ → อนุมัติแก้)
**priority:** false-positive reduction (ไม่กระทบการจับ typo จริง)

## 1. ความเสี่ยงเดิม
กฎตรวจคำสะกดฟ้องคำ **ถูกต้อง** ว่าผิด:
- **ITM010** จับ "ิ์" ใน **บริสุทธิ์** (น้ำตาลทรายขาวบริสุทธิ์) ว่า "การันต์หลังสระ" — แต่ ธิ์/ทธิ์ ถูกต้อง (บาลี-สันสกฤต: บริสุทธิ์/สิทธิ์/ฤทธิ์). ×4
- **ITM011** จับ **กระเบื้องพื้น** ~92% ใกล้ "กระเบื้องปูพื้น" ว่า "อาจสะกดผิด" — แต่เป็นชื่อสินค้าจริง (ชื่อสั้น). ×7

## 2. Root cause
1. `THAI_TYPO_PATTERNS` มี `[ะาิีึืุู]์` รวม ิ ทั้งที่ ิ์ ถูกเกือบทุกคำ → over-broad
2. "กระเบื้องพื้น" ไม่อยู่ใน PYTHAINLP_WHITELIST → fuzzy จับเทียบ

## 3. ทางแก้ (config_base.py)
1. pattern: `[ะาิีึืุู]์` → `[ะาีึืุู]์` (เอา ิ ออก) — robust ครอบ สิทธิ์/ฤทธิ์ อนาคต
2. PYTHAINLP_WHITELIST += `'กระเบื้องพื้น'`

## 4. ไม่ทำลายการจับจริง
typo จริง **เก็บครบ**: แกลอน→แกลลอน · มั้วน→ม้วน · หล็กฉาก→เหล็กฉาก · ตู้คอนซูเมอร์→คอนซูมเมอร์ · บสังกะสี→สังกะสี · ปลายสว่าง→สว่าน — ยังฟ้องเหมือนเดิม
