# หน้าแดชบอร์ดใหม่ (มินิมอล) + ตอบคำถามที่ถาม

## สรุปสิ่งที่เพิ่ม/แก้

1. **หน้าแรก `/` เปลี่ยนเป็นหน้ามินิมอลที่มีกราฟราคา BTC จริง** พร้อมจุดที่เอเจนต์
   เข้า/ออกไม้ (▲ เขียว = เปิด, ▼ แดง = ปิด) — ไม่ใช่ภาพ "เรือนใหญ่" (wallpaper) อีกต่อไป
   - หน้าควบคุมเต็มรูปแบบเดิมย้ายไป **`/full`** (กดลิงก์มุมขวาบนได้)
2. **โชว์ตัวเลขครบตามที่ถาม** (ทั้งหมดเป็นค่าจริงจาก ledger หักค่าธรรมเนียมสองขาแล้ว):
   - **อัตราชนะ (Win Rate)** + จำนวนชนะ/แพ้/ไม้ที่ปิด
   - **เทรดลม (PAPER):** มูลค่าพอร์ต, เงินสด, กำไรวันนี้ (฿ และ %), กำไรที่รับรู้แล้ว
   - **ไม้ที่เปิดอยู่** + กำไรลอยตัว
   - **เป้ากำไรวันนี้:** เป็นยอด ฿ และ % พร้อมแถบความคืบหน้า (ตอบ "วันนี้จะได้ยอดเท่าไหร่")
   - **บัญชีจริง (Bitkub):** ยอด wallet จริง (อ่านอย่างเดียว) เมื่อเชื่อม key
   - **ตารางไม้ล่าสุด:** เวลา/ชนิด/จำนวน/ราคา/**กำไร-ขาดทุนต่อไม้ (สุทธิ)**
3. **แก้ API key เข้าไม่ได้ + login rate_limit_exceeded**

---

## ทำไม API key เข้าไม่ได้ (และแก้ยังไง)

มี 2 สาเหตุ:

1. **`rate_limit_exceeded` ตอน Login** — ตัวจำกัดอัตรา (100 req/นาที/ไอพี) ทำงานกับ
   *ทุก* คำขอรวมการ polling ของหน้าจอเอง พอ dashboard ยิง status ถี่ๆ มันก็เต็มโควตา
   แล้วเด้ง 429 ใส่การ login ของคุณเอง
   → **แก้แล้ว:** คำขอจากเครื่องเดียวกัน (loopback/localhost) **ไม่ถูกจำกัดอัตราอีกต่อไป**
   (ยังจำกัดเฉพาะคำขอจากเครื่องอื่นบนเน็ตเวิร์ก ซึ่งต้องมี credential อยู่แล้ว)

2. **`invalid or missing X-API-Key` ตอนกดเชื่อม Bitkub** — endpoint อันตราย (เชื่อม key /
   สั่งซื้อ / kill) ถูกล็อกด้วย control key เพื่อความปลอดภัย (ตั้งใจ ไม่ถอด) วิธีให้ผ่าน:
   - **วิธีที่ง่ายสุด:** ตั้ง `DASHBOARD_API_KEY=...` ใน `.env` → ระบบจะ **ฝังคีย์ให้หน้าเว็บ
     อัตโนมัติ** → กดเชื่อม Bitkub ได้เลย (ไม่ต้อง login)
   - **หรือ** ตั้ง `DASHBOARD_PASSWORD=...` แล้วกด **Login** ด้วยรหัสนั้น (ตอนนี้ login ทำงานแล้ว
     เพราะแก้ rate limit) เพื่อรับสิทธิ์ควบคุม

> หมายเหตุ: "เชื่อม Bitkub API key" = อ่านยอด wallet จริงแบบ **read-only** เท่านั้น
> ไม่ใช่การเทรดด้วยเงินจริง

---

## เงิน "ลม" vs "จริง" — ต่างกันยังไง

- **เทรดลม (PAPER):** เอเจนต์ทุกตัวเทรด *จำลอง* บนราคาจริงของ Bitkub ตลอดเวลา —
  ตัวเลข equity/กำไร/Win Rate/ไม้ต่างๆ บนหน้าจอ **คือผลจริงของการเทรดลม** (หักค่าธรรมเนียมจริง)
  นี่คือสิ่งที่ระบบทำอยู่ตอนนี้ (โหมด default = ปลอดภัย ไม่ใช้เงินจริง)
- **บัญชีจริง (Bitkub):** เมื่อเชื่อม key จะเห็น **ยอด wallet จริง** (อ่านอย่างเดียว)
- **เทรดด้วยเงินจริง (LIVE):** ถูก **ล็อกไว้โดยตั้งใจ (paper-only)** ต้องปลดล็อก 4 ด่านเอง
  ที่หน้า `/full` (engine=live + confirm token + ไม่มี KILL_SWITCH + breaker ปิด) —
  ระบบ/ผมจะ **ไม่** เปิดให้อัตโนมัติ เพราะเป็นเงินจริงและมีความเสี่ยง

ดังนั้น "กำไรเทรดจริงวันนี้" จะมีก็ต่อเมื่อคุณปลดล็อก LIVE เอง — ก่อนหน้านั้นตัวเลขกำไร
ทั้งหมดคือผลของการเทรดลม (ซึ่งเป็นค่าจริง วัดได้ ตรวจสอบได้)

---

## วิธีดู "เอเจนต์เทรดไม้ไหน ได้/เสียเท่าไหร่"

- บนกราฟ: จุด ▲ เขียว = ตอนเปิดไม้, ▼ แดง = ตอนปิดไม้ (วางตรงราคาที่เข้า/ออกจริง)
- ตาราง "ไม้ล่าสุด": แต่ละแถวบอกเวลา ชนิด (เปิด/ปิด+เหตุผล TP/SL/trail) ราคา และ
  **กำไร/ขาดทุนสุทธิต่อไม้** (เขียว=กำไร แดง=ขาดทุน)

## endpoint ใหม่ (สำหรับนักพัฒนา)

- `GET /api/prices/history` → `{"prices":[{"ts_ms","price"}...]}` (ป้อนกราฟตอนโหลด; live ต่อผ่าน `/ws`)
- `GET /api/trades` → `{"trades":[{type:FILL|CLOSE, ts_ms, qty/entry หรือ exit/pnl_net/reason}...]}`
- `GET /full` → หน้าควบคุมเต็มรูปแบบเดิม · `GET /` → หน้ามินิมอลใหม่ · `GET /classic` → UI เก่า
