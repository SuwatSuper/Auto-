# Kingdom Prime — Phase 5: ปลดลิมิต + ฝูงเอเจนท์ 150 ตัว + หน่วยความจำถาวร

สรุปสิ่งที่ทำตามที่สั่ง (ทุกอย่างเป็นของจริง ทดสอบผ่าน ruff + mypy + pytest 619 ผ่าน, coverage 87%).

## 1) เพิ่มเงินเป็นสิบล้าน + ปลดลิมิต + ความเสี่ยง 100% (ปรับเองได้ในหน้า Settings)

| รายการ | เดิม | ใหม่ | ปรับได้ที่ |
|---|---|---|---|
| เงินเริ่มต้น (paper) | 1,000,000 | **10,000,000 (สิบล้าน)** | `INITIAL_CAPITAL` ใน `.env` |
| เบรกเกอร์ 5/5 (ขาดทุนติดกัน) | สูงสุด 100 | **0 = ไม่จำกัด** (ไม่ตัดเองอีก) | Settings → "max consec. losses (0=ไม่จำกัด)" |
| ความเสี่ยง/ไม้ | สูงสุด 50% | **สูงสุด 100%** | Settings → "risk %/trade (≤100)" |

- เบรกเกอร์ `0 = ไม่จำกัด` หมายถึงระบบ **ไม่หยุดเทรดเองจากการแพ้ติดกัน** อีกต่อไป (ยังกด TRIP เองได้)
  หน้าจอจะโชว์ `ขาดทุนติดกัน X/∞`
- ปรับค่าได้สด ๆ ผ่านหน้า **ตั้งค่า** กด "บันทึกความเสี่ยง / Apply" — มีผลกับไม้ถัดไปทันที และถูกเซฟลงดิสก์

ไฟล์ที่แก้: `src/infrastructure/config.py`, `src/orchestration/control.py`,
`src/domain/risk/circuit_breaker.py`, `src/infrastructure/web/static/kingdom.html`

## 2) เพิ่มเอเจนท์ 150 ตัว (3 ฝ่าย × 50) + จัดหมวดหมู่ + คุยกันได้

โครงสร้างใหม่ทั้งหมด **154 ตัว** (รวมหัวหน้าฝ่าย + ศูนย์ข้อมูล) ทำให้ระบบมีเอเจนท์รวม **181 ตัว**:

| ฝ่าย | จำนวน | ทำอะไร |
|---|---|---|
| 📈 **ฝ่ายวิเคราะห์กราฟอดีต** (`hist_*`) | 50 | คำนวณกราฟ/ราคาในอดีต ทุก timeframe (วินาที/นาที/ชั่วโมง/วัน) — เทรนด์ + แพตเทิร์น |
| ⏱️ **ฝ่ายอ่านราคาปัจจุบัน** (`live_*`) | 50 | วิเคราะห์เดียวกันบนแท่งเทียนที่ **กำลังก่อตัว** = ราคาปัจจุบัน |
| 🎯 **ฝ่ายหาจุดเข้าซื้อ** (`entry_*`) | 50 | ล่าจุดเข้าซื้อ ส่งสัญญาณ BUY เข้าสายการตัดสินใจเดิม |
| 👔 หัวหน้าฝ่าย × 3 + ศูนย์ข้อมูลแท่งเทียน × 1 | 4 | สรุปฉันทามติแต่ละฝ่าย + แปลงราคาเป็นแท่งเทียนหลาย timeframe |

**ของจริงไม่ปลอม:** ทุกเอเจนท์คำนวณจากราคาจริงที่ถูก resample เป็นแท่งเทียน OHLC
(1s/1m/1h/1d) — ช่วงแรกจะขึ้น "อุ่นเครื่อง" อย่างซื่อสัตย์จนกว่าจะมีแท่งพอ

**13 วิธีวิเคราะห์จริง** (กระจายข้าม timeframe): EMA cross, RSI, MACD, Bollinger,
Donchian, Momentum/ROC, SMA slope, Stochastic, ATR, ยอด/ฐานยกตัว (HH/LL),
double top/bottom, engulfing, การเร่งโมเมนตัม

**คุยกันได้ (ผสานการทำงาน):**
- หัวหน้าแต่ละฝ่ายรวมเสียง 50 ลูกน้อง → สรุปเป็น **ฉันทามติ (bias)** แล้ว publish ขึ้น bus (`analysis.v1`)
- ฝ่ายหาจุดเข้าซื้อจะ **เข้าซื้อก็ต่อเมื่อ** วิธีของตัวเอง bullish **และ** ฉันทามติฝ่ายเห็นด้วย
- สัญญาณ BUY ไหลเข้า `signals.v1 → Supreme → เกตความเสี่ยง → Paper Trader` (สายเดิม)

ไฟล์ใหม่: `src/domain/analytics/swarm_methods.py` (วิธีวิเคราะห์, pure),
`src/orchestration/agents/swarm.py` (เอเจนท์ + ศูนย์ข้อมูล + โรงงานประกอบฝูง)
เชื่อมที่ `src/orchestration/runtime.py`. หน้า Dashboard → แท็บ **Agents** จะเห็นทั้ง 181 ตัว
แยกตามฝ่ายเรียบร้อย

## 3) หน่วยความจำถาวร — ปิดเครื่อง/กดกากบาทแล้วพรุ่งนี้ยังจำได้

- ทุกเอเจนท์มี **สมุดบันทึก (Learner)**: จำว่า **เคยผิดพลาดอะไร (❌)** และ **แก้/ปรับอะไรไปแล้วบ้าง**
- เซฟลง **เครื่องเรา** ที่ `data/state.db` (เปิดอยู่โดยค่าเริ่มต้น `PERSIST_STATE=true`):
  - **ทยอย ๆ เซฟ** ทุก 30 วินาทีระหว่างทำงาน (กันไฟดับ)
  - **เซฟตอนปิดระบบ/กดกากบาท** (graceful shutdown) อีกรอบ
- ตอนเปิดใหม่ (พรุ่งนี้) ระบบ **โหลดความทรงจำกลับ** ให้ทุกเอเจนท์ และจดบันทึก
  "🧠 จำจากเซสชันก่อนได้ (ความผิดพลาด + การแก้ไข)"

ไฟล์ที่แก้: `src/orchestration/agents/learning.py` (`to_dict`/`load_dict`),
`src/orchestration/runtime.py` (`_restore_memories`/`_persist_memories`/`_memory_loop`),
ตั้งเวลาเซฟได้ที่ `MEMORY_PERSIST_INTERVAL_S` ใน `.env`
