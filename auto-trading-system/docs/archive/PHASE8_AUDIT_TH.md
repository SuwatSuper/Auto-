## 🐞 บั๊กแฝง "เงินจริง" ที่เจอและแก้ (สำคัญสุด)
ล่าบั๊กเชิงลึกเส้นทางออเดอร์จริง เจอจุดที่ **เสียเงินจริงได้** — แก้แล้วทั้งหมด:

**🔴 CRITICAL**
- **C1 — ยิงออเดอร์จริงก่อนเช็คคลังเงิน**: เดิมยิง bid จริงก่อน แล้วค่อยเช็คคลัง (ถ้าคลังหยุด/เงินไม่พอ
  จะได้ position จริงที่ **ไม่มี stop ไม่มีการติดตาม**). แก้: **เช็คคลังก่อนยิงจริง** (`would_approve`)
  — คลังหยุด/เงินไม่พอ = ไม่ยิงเด็ดขาด
- **C2 — ปิด position จริงด้วยจำนวนผิด**: market order ได้เหรียญจริงต่างจากกระดาษเล็กน้อย เวลาปิดเลย
  ขายเกินที่มี → Bitkub ปฏิเสธ → ปิดไม่ได้ ค้างเสี่ยง. แก้: **ปิดด้วยจำนวนไม่เกินยอดจริงใน wallet**

**🟠 MEDIUM**
- **M2** — เดิมยิงจริงได้ทั้งที่ยังไม่ verify บัญชี → แก้: **บัญชีต้องกระทบยอดสำเร็จก่อน** ถึงจะยิงจริง
- **M4** — แจ้งเตือนวิกฤต ("ปิดจริงไม่สำเร็จ") อาจถูก GC ทิ้งกลางทาง → เก็บ ref กันหาย
- **M5** — rate limiter หลับทั้งที่ถือ lock → ทำทุกอย่างช้าเป็นทอด ๆ → แก้ปล่อย lock ระหว่างหลับ
- **M6** — ราคา NaN/Infinity ทำลูปเทรดพัง → กันราคาไม่ปกติทั้ง manual + paper trader
- **M7** — ออเดอร์ต่ำกว่าขั้นต่ำ Bitkub (~10฿) จะถูกปฏิเสธเงียบ ๆ → กันไม่ให้ยิง + กันเปิด live ถ้า cap ต่ำไป
- **M8** — เกณฑ์ samples ที่แสดงบนจอ (20) ไม่ตรงกับที่ใช้จริง (8) → ทำให้ตรงกัน

## ⚠️ จุดที่ยังเหลือ (เปิดเผยตรง ๆ ไม่โกหก)
- **M1** — โควตาไม้/วันรีเซ็ตเมื่อรีสตาร์ทระบบ (ทำให้ยิงได้เกินโควตาถ้ารีสตาร์ทกลางวัน — ไม่ทำให้เสียเงิน
  เพิ่ม แค่ count เพี้ยน). *ยังไม่แก้ — ความเสี่ยงต่ำ*
