# แก้ false-positive ในรายงานสรุปต่อบริษัท (company_summary)

แก้เฉพาะ "ชั้นรายงาน" (advisory) — `code_labels.py` / `super_ultra_viewer.py` เท่านั้น
ไม่แตะ engine ตรวจ/กฎ/golden hash. เทสเดิมผ่านครบ (รวม `test_super_ultra_viewer.py`).

## 1. มี master แล้ว แต่ช่องชื่อบจ. ขึ้น "ไม่มี master ตรวจไม่ได้"
อาการ: ใส่ ภ.พ.20 แล้ว แต่บริษัทที่ชื่อในบิลเว้นวรรคต่างจากทะเบียนแค่ "ช่องว่างเกิน"
(เช่น `บริษัท  เมฆาเจริญ` มี 2 เว้นวรรค) กลับโชว์ว่าไม่มี master.

สาเหตุ: `CMP004` (เว้นวรรคไม่ตรง) ถูกจัดเลน `master` → viewer แปลเป็น
"ไม่มี master ตรวจไม่ได้" ทั้งที่ตรวจกับ master เจอแล้วและชื่อตรง (ต่างแค่ช่องว่าง).

แก้: ย้าย `CMP004` ไปเลน `review` → ช่องชื่อบจ. ขึ้น "ตรง" (ช่องว่างเกินไม่ใช่ข้อผิดพลาด).

## 2. บิลที่อ่านวันที่ไม่ได้ ถูกแยกเป็นบล็อก "ไม่ทราบเดือน"
อาการ: บิล 1 ใบอ่านวันที่ไม่ติด → ถูกตัดออกเป็นกลุ่ม "ไม่ทราบเดือน" แยกต่างหาก
ทั้งที่เลขที่เอกสารบอกเดือนชัด (เช่น `IV6905000850` = งวด 05/69).

แก้: เพิ่ม `_period_from_iv()` — เมื่อบิลไม่มีวันที่ ให้เดาเดือนจาก "งวดที่ฝังในเลขที่เอกสาร"
(ตรรกะเดียวกับ `detect_iv_period_mismatch`). บิลจึงเข้ากลุ่มเดือนที่ถูกต้องและรวมยอดได้.
อ่านงวดจากเลขไม่ชัดจริง ๆ ค่อยขึ้น "ไม่ทราบเดือน" (กันเดามั่ว).

## 3. รหัสไปรษณีย์ขึ้นซ้ำ 2 บรรทัดต่อบิล
อาการ: `ADDR001` + `ADDR005` ฟ้องรหัสไปรษณีย์เรื่องเดียวกัน → โชว์ซ้ำ 2 บรรทัด/บิล.

แก้: ยุบให้เหลือ 1 จุด/บิล (เก็บอันที่บอก "ทะเบียน xxxxx") + คำสั้น "รหัสไปรษณีย์ไม่ครบ".

## 4. ข้อความ "running ลำดับรายการสินค้า" ให้สั้น เข้าใจง่าย ไม่มีเครื่องหมายพิเศษ
เดิม `ITM002/013/014` โชว์ดิบ เช่น `ลำดับซ้ำ: [5]`, `ลำดับขาดหาย (ฟันหลอ): [3]`,
`ลำดับไม่เรียง: #5→#3` และมี `ลำดับที่ ?` โผล่.

แก้คำใหม่ (ไม่มี `# [ ] : → ? ( )`):

| กรณี | ข้อความใหม่ |
|------|-------------|
| ลำดับซ้ำ | `ลำดับที่ 5 ซ้ำกัน` / `ลำดับที่ 5 และ 7 ซ้ำกัน` |
| ลำดับขาด | `ขาดลำดับที่ 3` / `ขาดลำดับที่ 3 และ 7` |
| ขาดเยอะ | `ลำดับสินค้าขาดหลายรายการ` |
| ไม่เรียง | `ลำดับสินค้าไม่เรียงกัน` |
| ไม่เริ่มที่ 1 | `ลำดับสินค้าไม่ได้เริ่มที่ 1` |
| เว้นช่วงผิดปกติ | `ลำดับสินค้าเว้นช่วงผิดปกติ` |

ป้ายช่อง (label) ของ `ITM002/013/014` รวมเป็น `ลำดับรายการสินค้าผิด`.
