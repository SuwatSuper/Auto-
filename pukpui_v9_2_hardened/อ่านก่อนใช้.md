# 📘 อ่านก่อนใช้ — ปุ้มปุ้ย v9.2 (ตรวจใบกำกับภาษี)

## 1. รันยังไง (กดปุ่มเดียว)

1. เปิด VS Code → **Open Folder** → เลือกโฟลเดอร์นี้
2. วางไฟล์ `.xls/.xlsx` ที่จะตรวจ **ไว้ในโฟลเดอร์เดียวกับสคริปต์**
3. กดไฟล์ `ปุ้มปุ้ย_ultimate_v9_modular.py` → กด ▶️ **Run**
4. จบ — ไม่ต้องตอบคำถาม (โหมด AUTO เปิดให้แล้ว)

> ครั้งแรกครั้งเดียว ถ้ายังไม่เคยลงไลบรารี: เปิด terminal (`Ctrl+~`) พิมพ์
> `pip install -c constraints.txt pandas xlrd openpyxl rapidfuzz numpy`

## 2. ได้ไฟล์อะไรออกมา

อยู่ในโฟลเดอร์ **`รีพอร์ต`** (สร้างให้อัตโนมัติข้างสคริปต์):

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `company_summary.txt` | **สรุปต่อบริษัท — ก็อปวางส่งบัญชีได้เลย** |
| `company_summary.xlsx` | ตารางสรุป + worklist รายบิล + วิธีอ่าน |
| `audit_v58_*.xlsx` | รายงานละเอียด 7 ชีต (ของเดิม) |
| `agent_report.txt` | บันทึกการทำงานของ agent |

## 3. อ่าน `company_summary.txt` ยังไง

แบ่ง 2 ส่วน:
- **`⚠️ ต้องแก้ก่อนส่งบัญชี`** (อยู่บน) — แต่ละบริษัทบอกชัดว่าช่องไหนผิด + **รายการต้องแก้รายบิล**:
  ```
  • [ไฟล์.xls | วันที่ | ชีต X | ลำดับ #N] ประเภทปัญหา — แก้อะไรเป็นอะไร
  ```
  → เปิดไฟล์นั้น ชีตนั้น บรรทัดนั้น แก้ตามที่บอก แล้วรันใหม่
- **`✅ ตรง พร้อมส่งบัญชี`** (อยู่ล่าง) — ก็อปทั้งบล็อกส่งบัญชีได้เลย

**สัญลักษณ์:** `❌`=ต้องแก้ · `⚠️`=ควรตรวจด้วยตา · `ตรง`=ผ่าน · `— ไม่มี master`=ไม่มี ภ.พ.20 มาเทียบ

## 4. `company_summary.xlsx` — 3 ชีต

- **สรุปบริษัท** — 1 แถว/บริษัท (เขียว=ตรง แดง=แก้ เหลือง=ควรตรวจ เทา=ไม่มี master)
- **ต้องแก้ รายบิล** — worklist: กรอง/เรียงได้ ไฟล์/วันที่/ชีต/ลำดับ/แก้ยังไง
- **วิธีอ่าน** — คำอธิบายสี/สัญลักษณ์

## 5. เรื่อง master (ภ.พ.20)

ตอนนี้ยังไม่มี master จริง → ช่อง **ชื่อบจ.** กับ **เลขที่ผู้เสียภาษี** จะขึ้น `— ไม่มี master ตรวจไม่ได้`
(ระบบไม่เดาว่าผิด/ถูก). ถ้ามี master จริงเมื่อไร วาง `master_companies.json` ไว้ข้างสคริปต์ → 2 ช่องนี้จะตรวจให้

## 6. ติดปัญหา

- `ModuleNotFoundError` → ลงไลบรารีตามข้อ 1
- ชื่อไฟล์ไทยมีปัญหา → รัน `main.py` แทน (ตัวเดียวกัน)
- ไม่เห็น `company_summary.txt` → ดูบรรทัดท้าย terminal ว่ามี `⚠️ ข้ามสรุปต่อบริษัท` ไหม
