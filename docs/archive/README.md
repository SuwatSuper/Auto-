# Archive — development history

These files document how Kingdom Prime was built and audited across its development
phases. **None of them are required to build, run, test, or deploy the system** —
they are kept for historical reference and traceability only.

The production entry points are the root [`README.md`](../../README.md) (English),
the Thai guides (`README_TH.md`, `START_HERE_TH.md`, `MANUAL_TH.md`,
`LIVE_TRADING_TH.md`), and the operational docs in [`../`](../) (`ARCHITECTURE.md`,
`RUNBOOK.md`, `LIVE_TRADING_RUNBOOK.md`, `EVENTS.md`, `SECURITY.md`, the ADRs).
