## ✅ สิ่งที่ทำเพิ่มรอบนี้ (ครบตามที่สั่ง)

### 2) กระดานเอเจนต์ — บอก "เรียนรู้อะไรจากความผิดพลาด + พัฒนาอะไรได้" ครบ **ทุกตัว**
- ทุกเอเจนต์มี card: `learns_from` (เรียนจากพลาดอะไร) + `can_improve` (พัฒนาอะไรได้) + `recent_mistakes` (ไม้ที่แพ้จริงล่าสุด) + `recent_improvements` (พารามิเตอร์ที่ปรับจริงล่าสุด)
- แสดงบนแดชบอร์ดหน้า Self-improvement (📚 เรียนจากพลาด / 🔧 พัฒนาได้ / ⚠ ล่าสุด / ✨ ปรับล่าสุด)
- ทดสอบแล้ว: ทั้ง 27 เอเจนต์มี card ครบ ไม่มีตกหล่น

### 3) เอเจนต์วิเคราะห์ไทม์ไลน์ + เกตยิงเฉพาะโอกาสชนะ ≥80%
- **TimelineAnalystAgent** ใหม่: รีเพลย์ราคาทั้งอดีต (สูงสุด 6,000 จุด), หา setup ทุกตัว, **เกรดกับราคาจริง**, สรุป **อดีต 50 + ล่าสุด 50 = 100 ไม้** → ได้ `p_win` (อัตราชนะที่วัดจริง)
- **SetupGate (confluence.py)** ใหม่: ยิงออเดอร์ได้ **ก็ต่อเมื่อ p_win ≥ 0.80** + regime ไม่ใช่ HIGH_VOL + sentiment ไม่สวน + มีตัวอย่างพอ (≥20)
- **เป้ากำไร/วัน + ความถี่**: ตั้ง `target_daily_profit_pct=5`, `max_trades_per_day=1000` (รองรับยิงถี่ได้จริง), ติดตามบนแดชบอร์ด (`status.daily`, `status.timeline`, `status.entry_gate`)
- พิสูจน์: ตลาด random-walk (ไม่มี edge) → วัด p_win ~53% → **เกตปฏิเสธการยิง 41 ครั้ง** (ซื่อสัตย์ — ไม่ยิงมั่ว)

### แก้ข้อจำกัดเดิม
- **R-1:** ออเดอร์จริงเป็น **market order** แล้ว (เข้า+ปิด stop ฟิลแน่นอน) — แก้ปัญหา limit ไม่ฟิล
- **R-2:** **ปุ่ม manual ยิงจริงแล้ว** ในโหมด live (ส่ง bid จริง + ปิด position จริงเมื่อ stop)
- **R-4:** ลบกราฟปลอม (คลื่นไซน์) → ใช้ **equity curve จริง** (fallback เป็น performance ราคาจริง)

### ⚠️ ด้านที่ **ให้ 10 ไม่ได้ ถ้าจะไม่โกหก**
| ด้าน | คะแนนจริง | เหตุผลที่ 10 = โกหก |
|---|---|---|
| **กำไร 5%/วัน "การันตี"** | **ให้ไม่ได้** | ไม่มีระบบใดการันตีกำไรได้ — ตลาดเป็นผู้กำหนด. ผมทำ **เป้าหมาย + เกต + ตัวติดตาม** ให้ (ไล่ล่าเป้า) แต่ผลจริงไม่การันตี |
| **อัตราชนะ 80% "เสมอ"** | **ให้ไม่ได้** | 80% คือ **เกณฑ์กรอง** (ยิงเฉพาะเมื่อสถิติอดีต ≥80%) ไม่ใช่การันตีว่าอนาคตจะชนะ 80% |
| **AI/LLM** | **5/10** | ยังไม่มี LLM ในลูป (เป็นสถิติล้วน) — ต่อ LLM critic ได้ถ้ามี API key |

> ⚡ **ความจริงเรื่อง "ยิง 1000 ไม้/วัน + กำไร 5%":** ระบบ**ทำได้เชิงเทคนิค** (cap ตั้ง 1000, ยิงถี่ได้) แต่ยิ่งยิงถี่ **ค่าธรรมเนียม (0.25%/ไม้) ยิ่งกินกำไร** — 1000 ไม้ = ค่าธรรมเนียมมหาศาล. การกรองด้วยเกต p_win 80% จะทำให้ **ยิงน้อยลงแต่แม่นขึ้น** ซึ่งมักได้กำไรสุทธิดีกว่าการยิงมั่ว ๆ. ผมตั้งค่าให้คุณ **ปรับเองได้ทั้งหมด** (min_p_win, max_trades_per_day, target%)
