# ระบบพัฒนาตัวเอง (Self-Improvement Loop) — ของจริง ไม่โกหก

## ตอบคำถาม "เอเจนต์ทุกตัวเป็นแบบนี้ไหม"
**ก่อนหน้านี้: ยังไม่เป็น** — EXP เดิมคือ "ปริมาณงาน" ไม่ใช่ "เรียนรู้จากผลลัพธ์"
**ตอนนี้: เป็นแล้ว** — เพิ่ม loop จริงครบ Execution → Reflection → Refinement + ความจำ + คะแนน + กระดานเรียลไทม์

## ⚠️ ความจริงเรื่อง LLM (ห้ามโกหก)
ระบบนี้ **ไม่ได้ใช้ LLM เป็นโค้ช** — เป็น **self-improvement เชิงสถิติ/ปรับตัวจากผลลัพธ์จริง** (ไม่ต้องเทรน ไม่ต้องมี key) แดชบอร์ดระบุชัดว่า `LLM critic: disabled (no API key)` — **ไม่แอบอ้างว่ามี AI โค้ช** ถ้าต้องการ LLM critic จริง ต้องใส่ Anthropic API key (มี hook รออยู่ ปิดไว้)

---

## กลไก 3 ขั้น (ทุกตัวเลขมาจากเหตุการณ์จริง)

### 1) Execution — ลงมือ
เอเจนต์กลยุทธ์ออกสัญญาณ BUY/SELL พร้อม**บันทึกราคา+เวลาไว้** (prediction)

### 2) Reflection — ประเมินผลจริง (Critic)
หลังผ่านไป 60 วินาที ระบบ**วัดผลจากราคาจริงที่ตามมา**:
- BUY แล้วราคาขึ้น ≥0.1% = ✅ ถูก · ลง = ❌ ผิด
- ได้ **hit-rate จริง** (ถูก/ทั้งหมด) ที่วัดได้ ไม่ใช่ตัวเลขแต่ง
- กรณีไม่ชัด (ขยับ <0.1%) = ทิ้ง ไม่นับ (ไม่ปั้นตัวเลข)

### 3) Refinement — ปรับปรุงตัวเอง + จำความผิดพลาด
ทุก 8 ไม้ที่วัดผลได้ ถ้าแม่น <45% → **ปรับพารามิเตอร์ตัวเองให้เข้มขึ้น** (จริง):
| เอเจนต์ | ปรับอะไรเมื่อแพ้บ่อย |
|---------|----------------------|
| Trend Follower | เพิ่มเงื่อนไขยืนยันเทรนด์ (EMA gap %) |
| Mean Reversion | ทำ RSI threshold ให้สุดโต่งขึ้น (30/70 → 28/72…) |
| Breakout | ขยายกรอบ Donchian (N 20→25…) เพื่อลดเบรกหลอก |

ถ้าแม่น >60% → ผ่อนเงื่อนไขกลับ · ทุกการปรับ **บันทึกลง journal พร้อมเหตุผลจริง**

### 🤝 เทรนกันเอง (Peer-Coaching)
ทุก 60 วิ ตัวที่แม่นสุดวันนี้ = **โค้ช** · ตัวที่แม่น <45% จะ "เรียนจากโค้ช" แล้วเข้มงวดขึ้น (บันทึกจริง)

## วัดผลได้ทุกตัว
- **คะแนนรายวัน 0–100** (รีเซ็ตเที่ยงคืน):
  - กลยุทธ์: 35% ความเสถียร + 65% ความแม่นจริง
  - ตัวอื่น: วัดจากความเสถียร (running/stale/restart/activity)
- **EXP/เลเวล** (สูงสุด 5000) จากปริมาณงานจริง
- ดูที่ `GET /api/agents/learning` หรือหน้า **Agents**

## กระดานเรียลไทม์ (หน้า Agents)
- **🏆 กระดานคะแนน**: จัดอันดับทุกตัวตามคะแนนวันนี้ + hit-rate + จำนวนครั้งที่ปรับตัว
- **🧠 ฟีดการเรียนรู้**: ทุกวินาที/นาที บอกว่า "เอเจนต์ไหนเรียนรู้อะไร" พร้อม timestamp จริง เช่น:
  - `[10:41:12] นักล่าเทรนด์: ผล BUY @2,500,000 → 2,515,000: ✅ ถูก (+0.60%)`
  - `[10:41:30] บอทสวนเทรนด์: แพ้บ่อย (แม่น 40%) → เข้มขึ้น RSI 30/70→28/72`
  - `[10:42:00] ผู้ชำนาญเบรกเอาต์: เรียนจากโค้ช นักล่าเทรนด์ → ขยายกรอบ N 20→25`
  - ทุกบรรทัด = เหตุการณ์จริง (ไม่มีบรรทัดไหนแต่งขึ้น)

> หมายเหตุ: ฟีด "ผลสัญญาณ" จะเริ่มไหลเมื่อมี**ราคา BTC จริง**เข้า (ต่อ Bitkub บนเครื่องที่เน็ตเปิด) — ในแซนด์บ็อกซ์ที่บล็อกเน็ตจะเห็นเฉพาะ event ระบบ (เช่น ฟีดหลุด/gc) ซึ่งก็เป็นของจริงเช่นกัน
