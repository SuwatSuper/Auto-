## ระบบเลเวล/EXP (ดูที่หน้า Agents)
- EXP = `ข้อความ×1 + สัญญาณ×15 + ตัดสินใจ×20 + บล็อก×10` (ลบโทษ restart×50) **จำกัดสูงสุด 5000**
- Level = `1 + EXP/100` (สูงสุด 50) · Rank: Rookie → Skilled → Expert → Master → Grandmaster → Legendary
- ยิ่งเอเจนต์ทำงานจริงมาก ยิ่งเก่งขึ้น (พัฒนาตัวเองตามผลงานจริง)
- หน้า Agents จัดกลุ่มตาม 5 หน่วย พร้อมแถบ EXP + ป้ายเลเวลรายตัว
