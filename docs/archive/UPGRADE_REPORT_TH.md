# 🚀 รายงานอัปเกรดระบบ — Kingdom Prime (รอบที่ 2)

วันที่: 2026-06-13 · ทุกการแก้ผ่าน `pytest 537 ผ่าน / 1 skip` · `ruff` ✅ · `mypy` ✅ (100 ไฟล์)

ทำตามที่สั่งครบทั้ง 4 เรื่อง: **ต่อท่อเทรดจริง · เอเจนต์ที่ปรึกษาให้มีผลจริง · ขยาย self-learning + consensus · เก็บกวาดบั๊ก + กันเงินจริง**

---

## ชุดที่ 1 — ต่อท่อเทรดจริง (แก้ B1 + B2)

**B1 — เทรดจริงยิงได้แล้ว**
- เพิ่ม `ExecutionAgent.set_rest_gateway()` และให้ runtime **ส่ง gateway เข้าด่านยิงคำสั่ง** ทุกจุด (ตอน build / ตอน connect บัญชี / ตอน disconnect)
- เดิม gateway ถูกสร้างแต่ไม่เคยส่งเข้า → ยิงจริงไม่ออก. ตอนนี้ **พิสูจน์แล้วว่ายิง `place_bid/place_ask` จริง** เมื่อเปิดครบ 4 เกต
- ⚠️ ยังเป็น **opt-in 100%**: ดีฟอลต์ยังเป็น `paper`. ต้องเปิด `execution_engine=live` + ใส่ confirm token + ไม่มี KILL_SWITCH + breaker ปิด + ต่อบัญชี ถึงจะยิงจริง

**B2 — แก้จำนวนเหรียญไม่ตรง + รู้ผลฟิล**
- ออเดอร์จริงกับ paper-mirror ใช้ **cap เดียวกัน** (`max_order_thb`) → ขนาดไม้ตรงกันเป๊ะ (พิสูจน์แล้ว: ออเดอร์จริง 49,975 บาท = paper notional 49,975 บาท)
- mirror พก **ราคาฟิลจริงจากตลาด** ไปเปิด paper (ไม่เดาว่าฟิลทันที) + log จำนวนเหรียญที่ได้รับจริง

**B5 — แดชบอร์ดบอกความจริง:** `execution_engine` สะท้อนค่าจริง (ไม่ฮาร์ดโค้ด "paper" แล้ว) + เพิ่ม flag `live_orders_armed` + ข้อความเตือนเปลี่ยนตามสถานะจริง (🔴 LIVE เมื่อจะยิงจริง)

## ชุดที่ 2 — เอเจนต์ที่ปรึกษาให้มีผลจริง (แก้ B3)

- **Kelly Position Sizer → ปรับขนาดไม้จริง:** เมื่อมีสถิติ ≥10 ไม้ จะปรับ `risk_per_trade_pct` ตาม Kelly **(คุมเพดาน [0.25%–2%])** มีผลกับไม้ถัดไปจริง
- **Trailing-Stop Bot → ป้องกันกำไรจริง:** ขยับ stop ของ position ที่เปิดอยู่ขึ้นได้จริง (ยกได้เกินราคาทุนเพื่อล็อกกำไร) ปิดไม้ด้วยเหตุ `TRAILING_STOP` **(พิสูจน์แล้ว: ปิดได้กำไรก่อนถึง stop ขาดทุน)**
- เปิด/ปิดได้ผ่าน `kelly_sizing_enabled`, `trailing_stop_enabled` (ดีฟอลต์เปิด)

---

## ชุดที่ 3 — ขยาย self-learning + consensus (แก้ B4)

- **Supreme = consensus จริง:** นับโหวตล่าสุดของแต่ละเอเจนต์ในกรอบเวลา (sliding window) → EXECUTE เมื่อ **เสียงเห็นพ้องถึงเกณฑ์** เท่านั้น
  - ตั้งเกณฑ์ได้: `supreme_buy_votes` / `supreme_sell_votes` (ดีฟอลต์ 1 = พฤติกรรมเดิม; ตั้ง 2+ เพื่อบังคับให้หลายกลยุทธ์เห็นตรงกันก่อนเข้า → noise ลด)
- **market_analyst (เอเจนต์สัญญาณหลัก) เรียนรู้แล้ว:** บันทึกทุกสัญญาณ → เกรดกับราคาจริง → มี hit-rate จริง + ปรับเงื่อนไขยืนยัน EMA ตามผลแพ้/ชนะเอง
- เพิ่ม `source` ให้ทุกสัญญาณ → Supreme รู้ว่าใครโหวต → นับ consensus ได้จริง

## ชุดที่ 4 — เก็บกวาดบั๊ก + กันเงินจริง

- **B6 (race ตอนรีสตาร์ท):** treasury อ่านจาก `paper.session.v1` (snapshot อะตอมมิก) โดยตรง → ไม่มี race, cash ไม่ย้อนหลัง 1 ไม้อีก
- **B7 (dead code):** ลบโค้ดที่สร้างแล้วทิ้งใน `bootstrap.py`
- **B9 (กันเงินจริง):** **เปิด live ไม่ได้ถ้ายังไม่ตั้ง cap ต่อออเดอร์** (`max_single_order_thb > 0`) → กันไม้แรกขนาดไม่จำกัดตอนที่ลิมิตอื่นยังเปิดกว้าง

---

## สิ่งที่ยังเป็นข้อจำกัด (พูดตรง)
- ออเดอร์จริงเป็น **limit ที่ราคา mark** — ถ้าตลาดวิ่งแรงอาจไม่ฟิลทันที (ยังไม่มี polling order-status เต็มรูปแบบ — เป็นงานรอบถัดไป)
- ค่าทุนยังเป็น **เงินจำลอง** สำหรับบัญชี paper; เทรดจริงใช้เงินจริงในบัญชี Bitkub ของคุณ (คนละก้อน)
- fee-optimizer / profit-vault ยังเป็น **ข้อมูลโชว์** (ยังไม่ feedback) — บอกตามตรง
