# ADR-0002: In-Memory Event Bus

## Status: Accepted

## Context

We need a pub/sub bus for decoupling the price feed from agents.

## Decision

Use an in-memory asyncio Queue-based bus (`InMemoryEventBus`) as the default implementation. The bus interface is a Protocol so it can be replaced with Kafka or Redis Streams.

## Consequences

- No external dependencies in development/test.
- Not persistent across restarts.
- Suitable for single-process deployment; needs replacement for multi-process.
