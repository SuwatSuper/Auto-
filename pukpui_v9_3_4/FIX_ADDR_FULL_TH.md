# สรุปการแก้ไข รอบ 7 — ที่อยู่เทียบ master "ครบทุก field ไม่มีรู"

วันที่: 2026-06-09 · เทสกับที่อยู่จริง (master ฉีหยวน vs บิล เจ.อาร์.)

## รูที่เจอ
_addr_smart_diff แยกที่อยู่ได้ 11 field แต่ "รายงาน/เทียบ" จริงแค่ 7:
  เลขที่ + แขวง/ตำบล + เขต/อำเภอ + ไปรษณีย์ + อาคาร/ชั้น/ห้อง
→ **ตก: จังหวัด, หมู่, ซอย, ถนน** (แยกได้แต่ไม่เคยฟ้อง) = รูที่ลูกค้าให้ปิด

## ปิดรูครบ — เทียบทุก field โดยแบ่งตาม "ความเชื่อถือได้ของ parser"
| ระดับ | field | ฟ้องเมื่อ |
|---|---|---|
| STRICT core (ERROR) | เลขที่ · ไปรษณีย์ · แขวง/ตำบล · เขต/อำเภอ · **หมู่** | ต่าง หรือ บิลขาด |
| SOFT core (ERROR) | **จังหวัด** | มีทั้งคู่แต่ต่างจริง |
| STRICT sub (WARNING) | อาคาร · ชั้น · ห้อง | ต่าง หรือ บิลขาด |
| SOFT sub (WARNING) | **ซอย** · **ถนน** | มีทั้งคู่แต่ต่างจริง |

** "SOFT" = ฟ้องเฉพาะเมื่อบิลมีค่าและต่างจริง — ไม่ฟ้อง "บิลไม่มี" เพราะ parser อาจดึงจังหวัด/ถนน
ที่ไม่มี label ไม่ได้ → กัน false-positive (ที่อยู่ถูกแต่เขียนย่อ/ไม่มี label = เงียบ)

## พิสูจน์ด้วยที่อยู่จริง 2 ชุด

→ ฟ้องครบ: ไปรษณีย์ / เขต-อำเภอ / แขวง-ตำบล / เลขที่ / **จังหวัด** (เดิมตกจังหวัด)
→ ที่อยู่เดียวกัน (ย่อ/ไม่มี label/สลับ) = เงียบ (ไม่ false-positive)
→ ต่างแค่ field เดียว = ฟ้องเฉพาะ field นั้น
